## 作者序

感謝三位微軟MVP前輩惠賜合著本書的機會，佳新非常榮幸和開心能夠參與其中並且一起完成本書。我負責第七章和第八章，分述以LINE Bot作為聊天介面，搭配Google Gemini人工智慧，如何透過Google AI Studio測試，並於Colab開發Python程式，最終部署到Cloud Run的整趟旅程。緊湊的章節，期待身為讀者的你也能同樣收穫滿滿。

當你拿起本書翻閱之際，或許你已經意識到，現代人寫程式已經不是從「Hello, World」入門，而是從挑選和串接LLM大語言模型開始，甚至很可能已經開始嘗試或者已經非常熟悉和AI協作一起寫程式了（Vibe Coding）！

時光倒轉29年，回到1996年，正值就讀高一的年紀，我在那年開始投稿電腦雜誌。又過了3年，來到1999年，就讀大二時開始翻譯電腦書，原文正是由Microsoft Press出版的，至於真正成為微軟MVP，則是2021年的事。再過4年，也就是2025年，終於有機會付梓第一本電腦書，內心充滿感激。

最後，謹將本書獻給Viki、Linus和Morris，我最鍾愛的奇步一家人。是你們支持我成為彰化最強，並且逐夢踏實地在故鄉彰化開創軟體公司事業，啟動數位轉型和永續發展的成長飛輪。
親愛的讀者們，請坐穩了，LINE Bot＋Google Gemini的學習列車，即刻啟程！
